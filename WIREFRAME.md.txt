- All user permissions

7. Main Use Cases
User Login
1. User enters username/email and password.
2. System validates the credentials.
3. System creates a session.
4. User is redirected to the dashboard.
Product Management
1. Admin opens the Products page.
2. Admin can add a new product.
3. Admin can edit existing products.
4. Admin can delete products.
5. Product information is stored in MySQL.
Product Search
1. User enters a search term.
2. System searches product names and descriptions.
3. Matching products are displayed.
Category Filtering
1. User selects a category.
2. System filters products by category.
3. Matching products are displayed.
Admin Monitoring
1. Admin opens the Admin Panel.
2. System calculates inventory statistics.
3. System displays total products, quantity, categories, and inventory value.
4. Low-stock products are displayed for monitoring.
